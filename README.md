# 🔙 Backtracking Algorithms — Presentation

An interactive slide deck covering the backtracking paradigm, state space trees, classic problems (N-Queens, Sudoku, graph colouring, Hamiltonian paths), constraint satisfaction, pruning strategies, and branch and bound. Aimed at mid-level software engineers.
